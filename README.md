# Beget Mail MCP

Beget Mail MCP подключает один почтовый ящик Beget к MCP-клиентам и агентам через Streamable HTTP. Входящая почта читается по IMAP, исходящая отправляется по SMTP.

## Инструменты

- `list_recent_emails` показывает заголовки последних писем.
- `search_emails` ищет по заголовкам и тексту письма, в том числе по фразам с пробелами и кириллицей.
- `get_email` читает письмо по IMAP UID без отметки «прочитано» и возвращает только имена вложений.
- `prepare_email` возвращает предпросмотр с адресатами, темой, текстом и одноразовым токеном.
- `send_email` отправляет письмо с теми же адресатами, темой и текстом по токену предпросмотра.

## Настройки Beget

По официальной справке Beget:

- IMAP: `imap.beget.com`, SSL, порт `993`;
- SMTP: `smtp.beget.com`, SSL, порт `465`;
- логин: полный адрес почтового ящика;
- SMTP-лимиты: до 30 писем в минуту и до 1500 писем в час.

Источник: <https://beget.com/ru/kb/how-to/mail/obshhie-svedeniya>

## Локальный запуск

### Docker

```bash
cp .env.example .env
```

Заполните `.env`, затем соберите образ и запустите контейнер:

```bash
docker build -t beget-mail-mcp .
docker run -d --name beget-mail-mcp \
  --env-file .env -e HOST=0.0.0.0 -e PORT=8000 \
  -p 127.0.0.1:8000:8000 beget-mail-mcp
```

### Python

Нужен Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
```

Заполните `.env`, затем экспортируйте значения удобным для вашей системы способом и запустите:

```bash
HOST=127.0.0.1 PORT=8000 beget-mail-mcp
```

Проверка состояния без доступа к почте:

```bash
curl http://localhost:8000/health
```

MCP endpoint: `http://localhost:8000/mcp`.

## Необходимые значения

- `BEGET_EMAIL` — полный адрес ящика;
- `BEGET_PASSWORD` — пароль именно этого почтового ящика;
- `MCP_BEARER_TOKEN` — отдельная случайная строка длиной не менее 32 символов.

Сгенерировать токен можно локально: `openssl rand -hex 32`. Не присылайте пароль или токен в чат и не добавляйте `.env` в Git.

## Подключение MCP-клиента

Клиенту нужна поддержка Streamable HTTP и заголовка `Authorization: Bearer <MCP_BEARER_TOKEN>`. Для клиента на том же компьютере укажите `http://127.0.0.1:8000/mcp`. Для удалённого клиента используйте доступный ему URL с HTTPS и тем же путём `/mcp`.

При отправке клиент должен показать предпросмотр и запросить подтверждение пользователя перед вызовом `send_email`. Сервер проверяет содержимое письма и токен, а подтверждение человеком обеспечивает клиент.

## Безопасность MVP

- секреты читаются только из окружения;
- MCP endpoint закрыт Bearer token;
- соединения с Beget используют TLS;
- письма читаются через `BODY.PEEK`, то есть не помечаются прочитанными;
- отправитель всегда равен `BEGET_EMAIL`;
- токен предпросмотра действует до 10 минут, принимается один раз и аннулируется при перезапуске процесса;
- тела писем и секреты не журналируются приложением.
